# Namaz Helper

**Your complete Islamic companion app** — prayer times, Quran, and daily Azkar in one place.

## Features

- 🕌 **Accurate Prayer Times** — Zuhr, Asr, Maghrib, Isha and more, with reminders
- 📖 **Quran** — two reading modes:
  - With translation (Urdu – Jalandhry & Maududi, Hindi, and Uthmani Arabic — Tanzil Project data)
  - Full-screen Indo-Pak page-wise reading mode (15 lines per page, traditional layout)
- 🤲 **Azkar** — daily morning/evening and situational duas
- 🌐 **3 Languages** — Urdu (Roman), Hindi, and English toggle throughout the app
- 🔕 **Silent Mode** — auto-silence during prayer times

## Download

APK available via the landing page: [namazhelper.blogspot.com](https://namazhelper.blogspot.com)

## Tech Stack

- Android (built with Google AI Studio / Gemini)
- Tanzil Project Quran data (Uthmani Arabic script, verified translations)

## Setup (for developers)

1. Open the project in Android Studio
2. Sync Gradle
3. Run on a physical Android device
